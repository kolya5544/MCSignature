Check that a Minecraft textures property was really signed by Mojang. Everything runs locally in your browser; the page does not send what you paste anywhere. When the signature is valid it also loads the skin and cape images from textures.minecraft.net to preview them.

How it works

Mojang signs the exact base64 text of the textures value (its ASCII bytes) with RSA-4096, PKCS#1 v1.5 and SHA-1. This page recomputes that check with the browser's built-in WebCrypto against every key from api.minecraftservices.com/publickeys. The keys are cached locally in keys.json, which a GitHub Action refreshes daily. You can also paste the live response above. Source: verify.js, under 80 lines.
